# Quality Platform

Sistema web para la gestión de auditorías e inspecciones de calidad.

## Objetivo

Permitir la planificación, ejecución y seguimiento de auditorías de calidad mediante una plataforma web accesible desde PC, tablet y celular.

## Alcance inicial

- Gestión de usuarios
- Gestión de procesos
- Checklists dinámicos
- Auditorías
- Hallazgos
- Acciones correctivas
- Evidencias fotográficas
- Reportes PDF
- Códigos QR

## Estado

Proyecto en fase de desarrollo.
